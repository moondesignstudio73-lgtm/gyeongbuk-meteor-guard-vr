# 운석 방어대에 오신 것을 환영해요!

우주선에 올라 지구로 다가오는 운석을 막아 주세요. 조준점을 운석에 맞추고 잠시 기다리면 레이저가 자동으로 발사돼요.

## PC에서 시작하기

1. 다운로드한 ZIP 파일을 전부 압축 해제해 주세요.
2. 폴더 안의 **Start-Mouse.cmd**를 두 번 눌러 마우스로 시작하세요. Unity 설치는 필요 없어요.
3. 난이도를 고른 뒤 **시작**에 조준점을 맞춰 주세요. 처음이라면 **체험** 또는 **쉬움**을 추천해요.
4. 조준 연습을 마치면 우주로 출격해요!

`MeteorDefenseVR.exe`로 실행하면 연결된 장치에 맞춰 조작 방법을 선택해요. 카메라를 사용하는 경우 화면의 빛나는 점을 차례대로 바라봐 주세요.

준비 화면에서는 우주선 주변의 빛과 진행 표시가 움직여요. 준비가 끝나면 시작 화면이 나타나요. 임무 중에는 새로운 단계가 시작될 때 **스테이지 2**처럼 현재 단계가 중앙에 표시돼요.

출격할 때는 격납고 문이 열리고 기체가 빠르게 날아오른 뒤 조종석으로 이어져요. PC에서는 가속에 맞춰 출동 장면의 흔들림과 속도 효과가 커져요. VR에서는 시점을 흔들지 않는 출동 화면으로 보여 줘요.

## 이렇게 플레이해요

| 하고 싶은 일 | 방법 |
| --- | --- |
| 주변 둘러보기 | 마우스를 천천히 움직여요. |
| 운석 공격하기 | 가운데 조준점을 운석에 맞추고 잠시 기다려요. 초록색으로 바뀌면 자동으로 발사돼요. 클릭하지 않아도 돼요. |
| 메뉴 선택하기 | 조준점을 원하는 메뉴에 맞추고 잠시 기다려요. |
| 잠시 쉬기 | PC에서는 **Esc**를 눌러요. 다시 누르거나 **게임으로 돌아가기**를 선택하면 이어서 플레이해요. |
| 움직임 조절하기 | 시작 화면이나 쉬는 화면에서 **시점 설정**을 열어 감도와 화면 흔들림을 바꿔요. |

카메라로 조작할 때는 고개를 천천히 돌려 주변을 살펴보세요. VR 기기를 사용할 때는 안내 선생님의 설명에 따라 착용해 주세요.

## 어떤 난이도를 고를까요?

- **체험:** 짧은 임무로 조작을 익혀요.
- **쉬움:** 앞쪽 운석부터 차근차근 막아요.
- **보통:** 앞쪽과 좌우를 살피며 도전해요.
- **어려움:** 모든 방향에서 다가오는 운석에 도전해요.

## 화면 읽기

- **방어막:** 운석을 놓치면 줄어들어요. 가까이 오는 운석부터 막아 주세요.
- **남은 운석:** 이번 구역에서 막아야 할 운석이에요.
- **점수:** 운석을 맞히며 쌓은 점수예요.
- **명중률:** 발사한 레이저 중 운석에 맞은 비율이에요.
- **등급:** 이번 도전의 성적이에요. 다시 도전해 더 좋은 기록을 노려 보세요!

능력을 얻으면 측면 상태판에서 **공격력 강화·속사·다중 레이저·과부하 레이저·운석 감속**의 남은시간을 확인할 수 있어요. 능력으로 얻은 **방어막**은 앞으로 공격을 막아 줄 횟수를 표시해요. 시간이 2초 이하로 남은 능력은 황색으로 바뀌어요. **선체 회복**과 **전자기 충격파**는 사용 즉시 화면 안내로 알려 줘요.

## 임무를 마치면

결과 화면에서 이번에 해낸 일 한 가지와 다음 등급까지 필요한 점수를 확인해요. 최고 S등급이면 최고 등급을 알려 줘요. 아직 운석을 격파하지 못했다면 첫 격파에 도전해 보세요!

결과가 나타나면 **다시 출격**이나 **기지 메뉴**를 선택할 수 있어요. 글자가 모두 나타날 때까지 기다릴 필요는 없어요.

기지로 돌아온 뒤 **다시 출격**, **난이도 바꾸기**, **랭킹**을 선택할 수 있어요. 쉬고 싶다면 **체험 마치기**를 선택해 다음 대원에게 자리를 넘겨 주세요.

방어막이 모두 소진되면 손상된 기체가 기지로 돌아와 착륙해요. 격납고 문이 닫히면 이번 도전의 결과가 나타나요. 귀환 중에도 점수와 기록은 그대로 보존돼요.

## 도움이 필요할 때

- ZIP 안에서 바로 실행하지 말고 파일을 모두 꺼낸 뒤 실행해 주세요.
- 다른 PC로 옮길 때는 실행파일 하나가 아니라 **폴더 전체**를 복사해 주세요.
- 눈이나 얼굴을 잘 인식하지 못하면 **Start-Mouse.cmd**로 마우스 플레이를 시작할 수 있어요.
- 플레이 중 불편하거나 어지러우면 잠시 멈추고 안내 선생님에게 알려 주세요.

시점 설정은 시작·일시정지·결과 화면의 아래 중앙에 있어요. 마우스 감도, 위아래 반전, 조준점 표시와 화면 흔들림을 바꿀 수 있어요. **닫기 / Esc**로 설정을 닫고, 다시 **Esc**를 누르면 쉬던 게임으로 돌아가요.

잠시 쉴 때는 전투·스테이지·연습 안내와 조준 표시가 숨겨져요. 게임으로 돌아가면 남은 안내가 이어져요.
