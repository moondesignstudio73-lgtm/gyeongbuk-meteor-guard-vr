# 플레이어 안내와 게임 연출 업데이트

기준: `codex/cockpit-visual-restore`, Windows 미리보기 이후 최신 소스.
추가 작업 범위는 [플레이 검토 기획안](GameDesign/PLAY_REVIEW_20261019.md)을 따른다.

추가 필수 기준: 텍스트 크기·잘림·겹침·대비·배치를 장식보다 먼저 해결한다. 시작, 로딩, 튜토리얼, 전투, 보스, 일시정지, 설정, 격납고, 결과, 재시작, 경고/보상을 실제 렌더로 점검한다. 창 비율과 긴 한글, 최대 숫자, 동시 표시, 비활성 상태를 확인하며 과도한 글자 축소로 문제를 감추지 않는다. 실제 HMD는 별도 미검증으로 명시한다.

## 검사 기록

### 10월 20일 추가 요청: 외부 기체 출동과 패배 귀환

- 출동: 격납고 문 개방, 기체·엔진 점화, 카메라 방향 급가속, 전투 시점으로 페이드 연결. 기존 LaunchSequence의 진행 상태에 동기화한다.
- 패배: 결과 스냅샷을 먼저 보존하고 5.2초 동안 손상 기체 접근, 격납고 진입, 착륙, 문 닫힘을 진행한 뒤 결과를 공개한다. 귀환 중에는 결과 자동 종료 시간이 소모되지 않는다.
- PC의 연출 전용 카메라에 속도 비례 흔들림과 방사형 모션 블러를 적용한다. 플레이어 카메라 좌표와 추적 시점은 바꾸지 않는다. XR에서는 외부 장면을 패널로 표시하고 흔들림·블러를 끈다.
- 초기화·재도전·일시정지, 결과 점수 보존, 이미 귀환한 뒤 중복 귀환 방지를 실제 장면에서 검사했다. 전체 관련 30개 중 29개가 먼저 통과했고, 남은 검사의 고정 대기시간을 완료 상태 기반으로 보정한 뒤 재검사 1개가 통과했다.
- 근거: `Docs/PlayerCopyQA/base-flight-regression.xml` 및 `base-flight-final.xml`. 실제 렌더는 `Docs/BaseFlightQA/`의 출동·손상 접근·착륙·문 닫힘·결과 화면이다.
- Suno 신규 음원 제작은 브라우저 연결이 막혀 대기 중이다. 이번 연출은 기존 게임 음원을 사용하며 새 Suno 음원이 포함됐다고 표시하지 않는다. HMD 검증도 별도 대기다.
- 첫 Windows 실행 검사에서 런타임 검색으로만 사용한 연기 셰이더가 제거되는 문제를 발견했다. 배포를 중단하고 전용 연기 셰이더를 Resources에 포함하도록 변경했다. 최초 실패 빌드는 배포 대상에서 제외하고 수정 빌드로 실행 검사를 다시 진행한다.

- 안내 문구 1차: 37개 중 34개 통과. 이전 문장/문자 수를 전제로 한 3개 검사를 새 문구와 실제 표시 검증에 맞춰 수정했다.
- 연출 및 관련 회귀: 17개 전부 통과. FlightTransition, UiMotion, GameFeel, StageProgression, TutorialController, TutorialSafeZone, EducationEntry 포함.
- 시각 검사에서 준비 화면의 사용자 정의 도형에 CanvasRenderer가 누락된 점과 조종석 뒤쪽에 가려지는 문제를 발견해 보정했다. 시작·재준비 화면의 우주선/궤도/상태/진행률을 다시 확인했다.
- 실제 HMD, 눈 추적 정확도, 소리 청감은 아직 검사하지 않았다. PC 검사 결과와 구분한다.

## 배포

모든 요청 항목 구현·검증 후 같은 커밋으로 새 Windows 실행본을 빌드한다. 실행본의 BUILD_IDENTITY.json, ZIP 해시, GitHub 릴리스 및 실행 경로를 이 기록에 연결한다. 9월 18일 실행본은 이전 버전으로 유지한다.
