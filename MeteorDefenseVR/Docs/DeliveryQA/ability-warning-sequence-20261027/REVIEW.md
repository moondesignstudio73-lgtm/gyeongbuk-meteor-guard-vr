# 능력 상태와 저체력 경고의 겹침 수정

기준 제품은 372a75f다. 최대 3개 능력(속사·다중 레이저·방어막)의 실제 획득, 유지, 소모 및 만료를 800×600과 1280×720에서 검사하다 두 문제를 재현했다.

1. 저체력 경고의 배경이 오른쪽 상태/능력 패널에 겹친다. 1280×720에서는 속사 글자 앞부분도 덮는다. 수정 전 경계 검사에서 14개 표본이 실패했다.
2. EMP 확대 중 흰 구체가 전투 화면을 불투명하게 가린다. 런타임 URP 재질은 Surface만 Transparent로 지정했고 실제 알파 혼합과 깊이 쓰기는 불투명 상태였다.

저체력 경고 전체를 오른쪽 패널 앞에서 끝나도록 옮겼다. 글자 크기·필수 문구·표시 시간과 고정 상태 패널 위치는 유지한다. EMP에는 원래 알파 0.18이 적용되도록 투명 혼합·깊이 쓰기·렌더 큐 설정을 연결했다. 크기·지속 시간·피해·판정·새 효과를 추가하지 않았다.

## 기존 근거의 재사용

- [속사·다중 실제 발사](../powerup-feedback-20261021/verification.md): 25cbe19의 실제 추가 공격, 쿨다운, 만료/갱신/재사용 근거다.
- [버프 가독성](../buff-readability-20261021/verification.md): d748a47의 8종/최대 3개/방어막 소모/만료 근거다. 이후 상태 패널 높이와 고정 배치가 바뀌었으므로 현재 겹침 통과로 재사용하지 않았다.
- [획득과 폭발](../pickup-explosion-readability-20261024/verification.md): c8d3e93의 획득 안내, 실제 콜라이더와 시선 체류, 폭발 뒤 글자 배경 근거다.
- [직전 고정 표적 타격](../player-hit-sequence-20261027/REVIEW.md): 점수판이 표적을 가리지 않았던 고정 조건의 비교 기준이다. 모든 겹침 조건의 통과 근거가 아니다.

## 검사 방법

[공유 검사 코드](../../../Assets/_Project/PcInput/AbilityWarningSequenceProof.cs)를 편집기 테스트와 명시적 Windows QA 옵션에서 함께 사용한다. 일반 실행에서는 생성되지 않는다. 실제 장면의 풀 아이템을 유형별로 선택해 생성하고 시선 레이를 주입한다. 생산용 Raycast/0.55초 체류/Collect/Activate를 통해 한 번씩 획득한다. 자연 확률 드롭이나 해당 단계까지 캠페인 진행을 검증하는 것은 아니다. 최대 활성 3개 설정과 실제 자산의 효과/시간을 그대로 쓴다. 회복·EMP는 즉시 능력이므로 활성 3개 목록을 밀어내지 않는다.

체력 100→10은 실제 충돌 피해 호출, 방어막은 실제 피해 가로채기/차단 이벤트로 3→2→1→0과 체력 유지 확인, 회복은 10→30 확인, EMP는 실제 대형 표적 파괴와 점수 이벤트 확인이다. 추가 실제 보조 공격으로 점수 안내가 EMP 안내를 대체하는 시점도 남긴다. 저체력 경고는 타이머를 조작하지 않고 실제 주기 표시를 기다린다. 속사·다중은 정상 시간 경과로 만료되고 횟수제 방어막만 남는지 확인한다. 남은 시간을 수동으로 설정하지 않는다.

카메라 렌더 크기만 제어하며 자동 사격은 끈다. 표적 이동은 고정한다. 게임 시간 step은 1/60초지만 능력/경고는 원래 unscaled 시간 경로를 쓰므로 게임 시각과 실제 경과 시간은 같지 않다. 각 상태/이벤트 파일에 두 시각을 남긴다. 한 프레임 뒤 캡처에서 0.1초 주기 상태판이 이전 체력을 잠깐 표시할 수 있으므로 회복 settled 표본을 별도로 확인한다. 비활성 라벨에 남는 이전 문자열은 화면에 남은 것으로 세지 않는다.

## 증거 구분

- Before: 수정 전 14개 상태/능력-경고 겹침. 초기 검사의 상태 일치 통과가 시각 통과를 뜻하지 않아, 원본에서 발견한 겹침을 경계 검사에 추가해 재현했다.
- WarningOnly: 경고 배치만 수정한 중간 확인. 겹침은 해소됐지만 EMP 불투명 원이 남았다. 배포 후보가 아니다.
- Editor: 최종 편집기 표본 및 관련 기능 회귀 결과는 after.xml에 기록한다.
- Native: 최종 ZIP 압축 해제 실행의 D3D12 검사와 표본을 별도로 기록한다. 아직 없는 파일은 완료 근거로 세지 않는다.

일반 OS 플레이·HMD·초심자 이해도·실제 청취·모든 능력 조합·전체 5해상도·자연 캠페인 완주를 승인하는 검사가 아니다. 이번 겹침 조건은 보스 대신 저체력 경고를 선택했다. 외부 창 차단 재시도, Suno 우회, Drive 변경은 하지 않는다.

첫 실행은 시작 화면에서 비활성 HUD를 조회하지 못한 검사 오류였고 다음 실행은 Unity의 DragAndDropCache 파일 오류로 중단됐다. 작업용 캐시는 백업 후 재생성했다. 이 실패와 초기 시각 검사 폴더는 통과 증거에 포함하지 않는다. 사용자 설정과 기록은 별도 보존한다.
