# 경북 건강수호대: 혈관 속 세균을 잡아라

경상북도 전시 체험을 위한 VR 아이트래킹 게임의 웹 프로토타입입니다. 현재 버전은 실제 시선 추적 장비 없이 핵심 게임 루프와 판정 감각을 검증할 수 있도록 제작되었습니다.

## 실행

정적 웹앱이므로 `index.html`을 직접 열거나 로컬 서버로 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 입력

- 마우스 이동: 시선 이동
- 대상 위에 0.2초 이상 머무르기: 조준 잠금
- 클릭 또는 Space: 깜빡임 공격
- Enter: 체험 시작
- R: 결과 화면에서 다시 시작

## 현재 구현 범위

- 입력 연습과 조준 잠금
- 45초 게임 루프
- 일반·빠른·보스 세균
- 적혈구 오인 공격 판정
- 점수·콤보·보너스·결과 등급
- 반응형 레이아웃과 키보드 접근성
- Web Audio 기반 간단한 피드백 사운드

## 다음 개발 단계

1. WebXR 또는 Unity WebGL 입력 어댑터 추가
2. 실제 Quest Pro 시선·눈 감김 입력 연결
3. 인체 → 심장 → 혈관 인트로 연출
4. 캐릭터·파티클·한국어 음성 에셋 교체
5. 운영자 모드와 세션 로그 추가
